01CONTEXT

真实背景

本课采用薄壁、封闭端、均匀直管近似。环向应力由压差、平均半径和壁厚决定；轴向分量还叠加附加载荷。它不是厚壁管完整解。

热膨胀若受约束会引入压缩应力。这里用给定约束系数乘EαΔT近似，不模拟封隔器运动、接触、弯曲或屈曲。

05GLOSSARY

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
管柱 / Tubing string承担流动与载荷的井下管状结构。本课缩小为一段理想直管。
压差 / Differential pressure内侧压力减外侧压力。MPa；这里只取正内压差。
环向应力 / Hoop stress沿圆周方向的拉应力。σθ=ΔP·rm/t。
轴向应力 / Axial stress沿管轴方向的应力。端载＋附加拉力－受限热应力。
热膨胀约束温升引起的膨胀被限制。E=200000 MPa，α=12×10⁻⁶/°C。
von Mises应力按屈服准则组合多个应力分量。平面应力：√(σθ²+σz²−σθσz)。
屈服强度 / Yield strength材料进入明显塑性变形的参考强度。教学给定550 MPa。
假可行 / False feasible预测通过，但参考计算不通过。必须随代理误差一同检查。
合成教学资料由公开写明的公式与参数生成。不是生产井观测，不能推断现场准确率。
保留组 / Held-out group拟合之前分开的完整条件组。只做误差检查，不更新模型。
可行候选 / Feasible满足当前明确边界的选项。空结果也保留，不强行给推荐。
代理模型 / Surrogate用较小模型近似一个响应关系。必须与独立参考计算核对。
