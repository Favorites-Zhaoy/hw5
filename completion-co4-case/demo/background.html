01CONTEXT

真实背景

ICV是可调节流入的完井部件，分区之间通常需要隔离。本课只模拟两段独立流入，开度是无量纲比例，省略井筒压降和真实阀门特性。

高流量可增加当期产液，也可能在本课模拟器中加快含水增长与压力下降。用油量减去水处理惩罚定义目标，目标权重本身也需要说明。

04DIFFICULTY

技术难度与参考方向

难度 高

高：Q表本身简单；难点是模拟器可信度、观测离散、训练分布覆盖和评价目标变化后的策略失配。

低：数据和标签可直接使用；中：需要整理、分组和解释误差；高：缺乏可靠标签，或需要跨井与现场验证。

05GLOSSARY

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
ICV / 流入控制阀调节单段进入井筒流量的完井部件。本课用开度比例抽象。
含水率 / Water cut产出液体中水的比例。当前状态；不是未来标签。
状态 / State选择动作时可观察的资料。时段、含水、压力与前一步动作。
动作 / Action策略可以选择的开度组合。[1,1]、[0.35,1]、[1,0.35]、[0.6,0.6]。
奖励 / Reward定义每一步目标的数值。油量减水与切换惩罚。
Q值 / Action value从当前状态采取动作后的折扣收益估计。离线迭代学得，页面冻结。
探索 / Exploration训练时尝试非当前最优动作。ε贪心，仅离线训练发生。
分布变化 / Domain shift执行条件与训练条件关系不同。RL-H03保留策略变差的结果。
合成教学资料由公开写明的公式与参数生成。不是生产井观测，不能推断现场准确率。
保留组 / Held-out group拟合之前分开的完整条件组。只做误差检查，不更新模型。
可行候选 / Feasible满足当前明确边界的选项。空结果也保留，不强行给推荐。
代理模型 / Surrogate用较小模型近似一个响应关系。必须与独立参考计算核对。
