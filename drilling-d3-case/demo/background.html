01CONTEXT

真实背景

井斜是井眼偏离垂直方向的角度，方位描述水平朝向。MD沿井眼长度，TVD是垂直距离；本课二维示意只比较一个剖面。

相同的转向动作，在不同地层和工况下不一定产生相同井斜变化。先由成对观测学习响应，才有可比较的预测。

04DIFFICULTY

技术难度与参考方向

难度 中

中至高：基本优化可以实现，难点在响应辨识、坐标关系和约束可信度。本课只做离线二维模拟。

低：数据和标签可直接使用；中：需要整理、分组和解释误差；高：缺乏可靠标签，或需要跨井与现场验证。

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
井斜 / Inclination井眼偏离垂直方向的角度。轨迹状态，°。
方位 / Azimuth井眼在水平面的朝向。本课二维模型不计算该维度。
MD / 测量井深沿井眼路径的长度。与TVD不能混用。
TVD / 垂直井深相对基准面的垂直距离。本课使用简化剖面深度。
靶线 / Target path希望轨迹接近的空间路径。优化目标的参照。
工具响应一次动作引起的方向变化。岭回归的拟合目标。
岭回归 / Ridge带正则项的线性响应模型。拟合交互特征，非固定手写增益。
滚动预测每一步重看当前状态再选动作。候选评分不使用未来真实响应。
拟合资料 / Fit data用来学习参数与响应关系的资料。标准化、权重和门槛只从这些资料获得。
保留组 / Held-out group预先隔开的另一口模拟井或另一批工具。不参与拟合，用来检查结果。
代理模型 / Surrogate用观测数据近似输入与响应的关系。预测用于比较候选，不等于真实井况。
