01 / PROFESSIONAL BACKGROUND

顶替要充分，循环压力也要留在边界内。

固井把水泥浆放进指定环空，关键是替走原有钻井液。提高排量有助于流动，也会增加摩阻压力；设计需要同时看顶替和压力窗口。

01CONTEXT

真实背景

前置或隔离液先与钻井液接触，后续水泥浆向上顶替。残余钻井液、混浆和通道会影响水泥环连续性，顶替效率是模拟体积被目标浆体替换的比例。

套管偏向一侧后，窄边间隙更小，流动阻力和清除条件改变。仅增加总排量不保证窄边完全被替净，几何与流变必须一同看。

05GLOSSARY

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
顶替 / Displacement一种流体把另一种流体移出目标位置。响应目标的物理过程。
隔离液 / Spacer置于两种不宜直接混合流体之间的液体。候选体积，m³。
偏心率 / Eccentricity套管中心偏离井眼中心的程度。教学归一化输入，0–1。
ECD / 等效循环密度把静液柱和环空压降一起换成密度。先筛选的上界，g/cm³。
PV / 塑性黏度流变模型中与剪切速率相关的阻力参数。井况输入，mPa·s。
摩阻压降 / Friction loss流体通过环空时损失的压力。简化模型输出，MPa。
代理 / Surrogate用成对试验学习昂贵响应的近似。真正拟合的岭回归。
岭回归 / Ridge regression带系数约束的最小二乘拟合。12个多项式/交互特征。
可行域 / Feasible region满足已定义边界的方案集合。ECD和设计范围同时通过。
事后响应 / Post-search response选定之后再查看的模拟结果。防止用答案反选方案。
拟合组 / Fit groups用来学习权重、标准化尺度的模拟井或作业。整组隔开，不能把同一井相邻点随机分到两边。
保留组 / Held-out groups训练之前就隔开的另一组资料。只检查泛化，不能用其标签挑模型。
合成资料 / Synthetic data由公开脚本和固定种子生成的教学资料。有可复算的标签，但不证明现场有效。
