M1 岩屑岩性辅助识别 · 1.6.2
场景：录井 / m1。方法定位：传统计算机视觉手工特征 + kNN监督分类。
任务：照片级、三类别、单标签岩性辅助分类。没有CNN训练、反向传播或深度特征学习。

运行与导入
1. 直接打开 demo/index.html，可切换专业背景、案例流程、可视化示范。
2. 入口为自包含HTML，样式、脚本、公开图像和论文图均内嵌；不读取相邻资源，不需服务器或在线接口。
3. 在老师门户点击“添加案例”，选择完整 m1-cuttings-case 文件夹；ZIP需先解压。沿用 firstbreak-pick-case 的原规范，不改变其他同学案例导入协议。
4. 建议用Edge或Chrome打开；部分App本地预览可能忽略样式与脚本。

专业背景
以一份岩屑的旅程串起井底破岩、上返取样、观察描述和记录对比；点击环节联动示意图与说明。右侧是真实公开照片，左侧是示意井，二者不存在现场对应关系。
参照老师案例，依次介绍当前做法与问题、AI能做什么、需要准备什么、难度与参考方向。
解释岩屑取样、迟到与深度对应、已有岩性标签和图像分类边界。“认识三种岩性”默认展开。
岩性切换展示本例三类真实照片与原始标签；选中的样品会延续到案例流程和示范。论文图例使用岩屑识别研究中的不同类型、类内差异和泥浆污染照片，以及真实油气井岩屑薄片扫描，保留原标签、标尺、DOI和CC BY 4.0许可。
论文图中的Sand、Dolomite不直接等同于本例的“细砂岩”和“灰质白云岩”标签；薄片扫描与RGB照片成像方式不同。外部论文图不进入训练、验证或测试。来源与处理记录见FIGURE-SOURCES.json和SOURCES.txt。

案例流程
七步总览连接当前查询照片、颜色与纹理特征、最近参考图、实际票数和当前阶段评价。点击总览切换对应讲解；切换图片、k或权重时，相关结果随浏览器中的实际计算更新。
同一张查询照片贯穿七步；颜色和纹理是从裁切后图像分别提取的并行分支：
1. 数据集构建与划分：沿用公开标签、核对样本及元数据；训练集42张/12组，测试集24张/5组。
2. 图像预处理：中心ROI宽高各保留72%，Resize为96×96；不宣称完成岩屑分割。
3. 颜色特征提取：RGB每通道4个区间，计数归一化为12维直方图。
4. 纹理特征与特征拼接：Uniform LBP（riu2，P=8，R=1，10维）、全图梯度方向直方图8维、统计量4维，与RGB拼接成34维。
5. 特征缩放与距离度量：仅由当前拟合样本估计标准差，尺度下限0.01；颜色12维与其余22维分别平均平方差，再按权重合成欧氏距离。
6. kNN分类推理：近邻检索和等权多数表决；平票比较同类近邻平均距离，再按类别ID排序。
7. 模型评估与人工复核：训练集分组交叉验证、锁定参数测试与独立人工意见分开记录。

纹理描述子的定义
依据Ojala等2002年的旋转不变均匀模式LBP。圆周采样8点、半径1，非整数采样位置双线性插值。
循环二进制跳变数U≤2时，映射为1的数量（0..8）；其余模式映射到9。所有8个采样位参与模式判定，不再使用旧版code右移4位的简化映射。
仅统计94×94个内部位置，直方图归一化。LBP模式映射具有旋转不变性；整个34维向量含方向特征，不能宣称整体旋转不变。
8维梯度描述子是全图中心差分方向统计，不称为完整HOG。4项统计量为亮度、灰度对比度、边缘比例、清晰度变换。

评估协议
阶段1：只开放训练集查询和超参数探索。对训练集的12个井段组逐组留出验证，每张训练图只产生一次折外预测。
查询某训练图时，排除它所在的整个组；参考样本与特征缩放参数均只来自剩余组。
阶段2：点击“锁定参数并运行测试集”，固定k与颜色权重，使用全部42张训练图拟合尺度和近邻参考集，再开放24张测试图并计算指标。
本页会话锁定后不能继续调整超参数；亮度/对比度扰动仅用于当前查询的敏感性演示，批量评价使用原始成像条件。
这是公开教学子集，历史版本已展示同一批测试图。本版演示流程隔离，不宣称从未接触这些数据的独立盲测。刷新后再调参属于继续探索，不能视为新的独立测试。
跨井泛化仍需独立井数据，小样本分数不能直接外推现场效果。

交互与输出
可点击RGB区间定位实际像素，移动观察位置查看Uniform LBP圆周采样、模式跳变和梯度，核对当前折可用参考图的距离及34维数值，逐票执行kNN。
模型评估展示混淆矩阵、准确率与宏平均F1；人工复核不修改模型预测或分数。
CSV记录已有标签、原始成像条件下的预测、人工意见、k、颜色权重、复核时图像扰动、评估协议/阶段、描述子版本、源井深、来源提交与图像SHA-256。
人工意见保存在当前页面会话；导出CSV留存。井深图只显示当前评估样本，缺失井段保留间隔，不插值为连续地层。
门户的三部分之间会共享当前样品、k、颜色权重、锁定状态和本次人工复核；切换部分时返回该部分开头。刷新或离开案例后状态不保存，复核应导出CSV。独立页面的三个标签也共享当前会话。
支持键盘导航与减少动态效果；论文图例可展开查看。
