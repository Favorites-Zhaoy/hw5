01 / PROFESSIONAL BACKGROUND

让窄边留出空间，把扶正器放在需要的位置。

套管在井眼中会受重力和弯曲影响偏向一侧。扶正器用于改善位置与环空间隙；同样数量放在不同位置，最窄处的条件也可能不同。

01CONTEXT

真实背景

套管居中时各方向间隙相近；偏心后最窄边缩小。本课明确规定离壁率为最小间隙除以居中时径向间隙，100%表示居中，0%表示贴壁。

扶正器限制支点位置，但两支点之间的套管仍承受横向载荷。支点间距变大，挠度通常快速增加；井斜、刚度和井径变化影响最小间隙。

05GLOSSARY

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
扶正器 / Centralizer把套管保持在较居中位置的器材。本课理想支撑点。
离壁率 / Standoff ratio最窄间隙占居中间隙的比例。本课明确几何定义，%。
径向间隙 / Radial clearance居中时套管到井壁的距离。计算用m，展示mm。
井斜 / Inclination井段偏离竖直方向的角度。横向载荷输入，°。
挠度 / Deflection受横向载荷后偏离原轴线的量。简支梁模型，m。
弯曲刚度 / EI弹性模量与截面惯性矩的乘积。教学有效值，N·m²。
简支梁 / Simply supported beam两端限制横向位移的理想梁。每对邻近支点之间的近似。
组合搜索 / Combinatorial search逐个比较离散位置组合。经典AI/运筹优化，无训练。
可行方案 / Feasible plan所有采样点均满足最低离壁率。先筛选，再比器材数量。
固定端支点100m段两端已有的理想支撑。不计入内部器材预算。
相对器材成本每个相同扶正器记作1单位。只是数量指标，无现场货币报价。
拟合组 / Fit groups用来学习权重、标准化尺度的模拟井或作业。整组隔开，不能把同一井相邻点随机分到两边。
保留组 / Held-out groups训练之前就隔开的另一组资料。只检查泛化，不能用其标签挑模型。
合成资料 / Synthetic data由公开脚本和固定种子生成的教学资料。有可复算的标签，但不证明现场有效。
