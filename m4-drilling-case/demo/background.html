01 / DRILLING TIME / SEQUENCE SEGMENTATION

钻时变了，是地层变化还是工况变化？

钻时同时受岩石、钻压、转速和设备状态影响。先看物理关系，再用Volve真实记录检查变化候选；没有独立地质标签时保留判断边界。

01CONTEXT

真实背景

钻时表示钻进单位进尺所需的时间，与钻速互为倒数。相似工况下，它可以反映可钻性变化；钻压、转速、钻头磨损改变时，同一岩层的钻时也会变化。

划层不能只把曲线的每个拐点都当成层界。先对照工况，再与岩屑和测井资料对应，才能解释候选界面。

现场全景 / 机制示意

A

钻时和机械钻速，描述同一过程的两个方向

单位换算示例；这些数值用于解释定义，不是模型实验结果。

机械钻速 ROP
每小时钻进多少米，单位m/h。钻速越大，钻进同样进尺所需时间越少。
钻时 Δt
本课表示每米所需分钟数，单位min/m，所以Δt=60/ROP；若资料采用h/m，换算系数应改为1。
采样依据
钻时按井深进尺记录。停泵、接单根等非钻进时间要与实际钻进段区分，保持记录口径一致。
B

两种原因，都可能让钻时突然变大

对照“同层但工况改变”和“工况相近但地层改变”；曲线与层界均为机理示意。

地层因素
岩石强度、结构、胶结和磨蚀性等会影响破岩难度；岩性名称与可钻性并不是同一个量。
工况因素
钻压、转速、清岩条件及钻头状态也影响钻速。同一岩层内改变工况，曲线仍可能出现台阶。
识别顺序
先对照工况是否同步变化，再检查持续性及其他地质资料，避免把每个拐点都当成层界。
C

候选层界，要放回同一井深轴核对

钻进响应、岩屑描述与其他测井资料互相对照的结构示意；不是三类岩性的自动对应表。

井深基准
MD沿井眼测量，TVD为垂直距离。对齐前先确认基准与单位，二者不能混用。
岩屑与迟到
地面样品对应较早的钻进井段，混样和上返迟到会影响层界对比。
地层解释
钻时提供可钻性变化线索，还要结合岩屑、地层顺序和测井等资料解释。本课没有独立地质层界标签，响应变化仅作为候选。

04DIFFICULTY

技术难度与参考方向

难度 中

单曲线入门容易；工况变化、钻头状态和井段关联使现场划层更难。先做多源对齐，再讨论跨井验证。

低：数据和标签可直接使用；中：需要整理、分组和解释误差；高：缺乏可靠标签，或需要跨井与现场验证。

05GLOSSARY

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
钻时 / Drilling time每钻进一米需要多久。按井深采样的时间序列。
钻速 / ROP每小时钻进多少米。本例Δt=60/ROP。
钻压 / WOB施加在钻头上的轴向载荷。工况输入，不是岩性标签。
转速 / RPM钻具每分钟转动次数。影响钻速的输入通道。
LSTM / 长短期记忆网络顺序读取记录，并把前段状态带到当前。最多12条工况记录，12维状态；当前ROP不作为输入。
响应残差实际钻速与工况估计相差多少。log(实测ROP)－log(估计ROP)，再检查沿井深的变化。
响应变化候选曲线或残差有明显变化的位置。没有地质层界真值，不能直接把候选写成地层。
MAE / 平均绝对误差平均每次估计偏离观测多少。本例以m/h比较同一留出井的ROP回归。
可钻性在给定工况下岩石容易钻进的程度。与钻速有关，但不能只凭钻速或响应残差命名岩性。
井深序列窗口当前位置及前段工况组成的有序记录。最多12条，超过2 m缺口断开；不当作等间隔时间。
MD / 测量井深沿井眼路径量到该点的长度。本课井深序列的空间坐标。
TVD / 垂直井深该点到参考面的垂直距离。与MD含义不同的坐标。
胶结与结构颗粒如何结合、岩石如何组织。影响可钻性的专业因素。
