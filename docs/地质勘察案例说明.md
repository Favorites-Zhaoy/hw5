# 地质勘察 · 四主题教学案例

入口：`index.html#/stage/geology`。本版按用户指定的在线参考 `https://favorites-zhaoy.github.io/hw5/?v=46320ee#/stage/mudlogging` 重做。总览直接从维护中的MudloggingStage组件派生，保留整图、方法放大、四个裁切图画入口、SVG流向与局部扫描、动效暂停和键盘操作。

四例的背景固定为“真实背景、技术前沿、示例数据、技术难度与参考方向、术语对照表”。流程为五步，03分成传统处理与智能处理两个重点单元，显示编号01、02、03、03、04、05。四例均按现有案例注册协议接入。

| 场景 | 原有方法标签 | 实际计算 | 交互与输出 |
| --- | --- | --- | --- |
| G1 地质剖面遥感解译 | CV | RGB最近类中心参照；80树随机森林，六波段和两个比值 | 3幅独立留出图，逐像元联动，得分门槛、覆盖率、CSV |
| G2 油气地球化学异常识别 | OPT | Isolation Forest多指标异常；DBSCAN空间密度聚类 | 3个独立区块，训练分位数、最少邻点、道路掩膜、CSV |
| G3 地质图件要素智能提取 | CV + NLP | CV图例颜色约束、闭运算、骨架追踪；三词模板OCR；字符TF-IDF与逻辑回归 | 3张扫描件，补缝半径，OCR定位，编辑图例后实际文本推断，图像坐标JSON |
| G4 露头裂缝自动统计 | CV | Canny、概率Hough、平行边缘去重 | 3个露头、9组检测参数、线段选择、比例标定、方向玫瑰图、P21、CSV |

OPT对应站点既有方法说明中的“聚类”和本场景的“异常检测、空间聚类”。DBSCAN在浏览器实际计算；最少点数包含自身，界面滑块显示所需其他邻点数，epsilon=145 m。C1参照采用同一DBSCAN与道路掩膜，避免混淆多指标方法与后处理的贡献。

## 数据与计算

所有实验资料均为程序生成的合成教学数据。配套AI生成说明图不进入训练或评价。

- G1：8幅训练、2幅检查、3幅留出，每幅48×32像元。整幅图隔离。网页使用训练后的树结构实际推断；光照扰动会重新计算分类，门槛只影响接受范围。全图正确率不随门槛变化，接受区正确率与覆盖率并列。
- G2：5个训练区块、1个检查区块、3个留出区块，每块252点。训练无监督模型与分位数时不使用生成标签；标签只评价组合异常，异常分数不是油气概率。
- G3：3张480×320合成扫描件；墨迹评价用2 px容差。模板OCR只识别J2s/K1m/T2l三个已知词形。96条合成图例语句训练TF-IDF逻辑回归，演示图例为另写的三条表述；相同文本在三张图上重复，不能算成9条独立语言测试。模型权重和词表保存在experiments.js，浏览器按相同TF-IDF与softmax实际计算；核对Python与JS得分误差小于0.00002。无已知词片段时应视为范围外文本，三类得分不能证明识别可靠。
- G4：3幅480×320模拟正射露头，每幅10条生成目标线迹；25/45/70 px最短线长与2/8/16 px最大缺口形成9组实际OpenCV输出。3 px容差评价针对未排除近水平线的原始候选，水平线过滤只改变几何统计。像素尺改变长度与面积，角度不变。候选线段数不是真实裂缝数。

G1/G2模型已实际拟合，树结构保存在`assets/geology/models.js`，浏览器实际执行分类树和孤立树的前向计算。默认输入下与Python保存得分的最大误差均小于1e-7。G1光照扰动改变反射率后重新分类，G2组分扰动改变浓度后重新计算异常；原始资料不改写。导出保留扰动参数与来源。G3文本推断和G2的DBSCAN也在浏览器实际运行。G3/G4经典计算机视觉结果按实际计算的参数组回放，没有宣称运行前沿论文中的深度网络。

源码：`assets/geology/`；案例注册：`assets/cases/geology.case.js`；生成工具：`tools/geology/prepare-experiments.py`。固定种子20261101。运行需Python、NumPy、Pillow、SciPy、scikit-learn及OpenCV：

```sh
python tools/geology/prepare-experiments.py
node tools/geology/rebuild-stage.cjs
node tools/geology/rebuild-lessons.cjs
node --test tests/geology.cjs
```

## 使用边界

遥感示例只解释地表类别；化探异常只作为复采线索；扫描图无地理配准，JSON使用左上原点的像素坐标；露头只测照片面内方向和P21，不输出三维走向、倾角或储量判断。

四例共用现有门户的三页签与本地资源，可从本机index.html离线运行。这次新增的是站内案例，未另行发布独立导入ZIP包。
