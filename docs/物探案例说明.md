# 物探：从问题、方法到可复核的成果

依据项目中的《石油勘探开发的智能化可能性地图-全网站设计.txt》，完成S1—S5五个具体场景，每例包含专业背景、案例流程和可运行示范。教学顺序沿用录井的“现场问题→传统处理→智能介入→作用依据→成果”，资料和算法按物探任务选择。

主题页用同一张新生成的现场图解释采集、处理、解释与预测的业务关系。断层与地震相是互补解释；初至与去噪可按资料需求组合；参数预测另需井约束。编号不代表五个程序必须依次执行。保留参考页的原图工位放大、局部动效、方法过滤、暂停和键盘操作。

## 案例、数据与算法

| 场景 | 原方法类别 | 本课实际计算 | 数据与评价边界 |
| --- | --- | --- | --- |
| S1 地震断层自动解释 | CV | 两层3×3×3卷积、ReLU及逐体素sigmoid；对照横向不连续属性 | FaultSeg3D作者公开的正演振幅和断层标签。3体训练、1体检查、3体留出；按体分组后取8×64×64窗口。默认FAULT-11，另外两体也可切换；局部像素F1不等于完整断面评价。 |
| S2 地震相智能分类 | CV | 两层二维卷积与十类softmax；对照线性多类逻辑回归 | 真实F3剖面与原v2的十类解释掩膜。8条inline训练、1条检查、3条留出。两方法都读取振幅和归一化垂向位置，卷积另读取邻域；层序位置先验及同工区留出范围明确。 |
| S3 初至波自动拾取 | TS | 一维时序卷积读取波形和9点能量，连续触发输出候选；对照STA/LTA短窗5、长窗35 | Ithra实测文件为400×120×120数组，本页展示第三轴20/60/100三个炮集索引的前64道。文件不含独立到时标签或采样间隔，页面不报告现场准确率或擅自换算毫秒。模型另用12炮受控模拟波形训练、1炮检查、3炮校准。 |
| S4 储层参数反演 | CV + OPT | 局部响应与低频井约束输入24/12单元神经回归；同输入Ridge参照；浏览器实际解有界平滑问题 | FORCE2020真实井曲线，3井训练、3整井留出。RHOB、DTC与深度构造简化一维响应，NPHI只作监督参考。输出为表观中子孔隙度候选；没有用真实现场地震完成井震标定。 |
| S5 地震资料噪声压制 | CV | 二维残差卷积预测噪声，输入减去残差；对照高斯平滑 | 在独立留出的F3全分辨率真实剖面窗口上加入固定种子的受控随机噪声；源图从第180行、第300列起取128×160窗口，不复用S2的缩小分类网格。原剖面仍有现场噪声，不称作干净真值；不宣称已验证面波、多次波压制。 |

训练后的卷积核、偏置、回归权重均保存在`assets/seismic/models.js`，网页实际前向计算。参考输出由Python独立生成，当前序列化输入下与浏览器计算的最大差异小于0.000005。模型不是论文网络的完整复现，论文成绩不作为本课成绩。

## 数据选择与来源

没有沿用岩屑照片或录井开发组的划分。先核对任务、标签、授权、文件字段和网页摘录成本，再选择：

- [FaultSeg3D作者仓库](https://github.com/xinwucwp/faultSeg)：有成对三维振幅与断层标签，适合可核对的三维分割入门；资料性质为作者正演合成，授权CC BY-NC 4.0。
- [Netherlands F3 Interpretation v2](https://zenodo.org/records/1471548)：真实叠后剖面与十类解释掩膜，CC BY 4.0。通过HTTP范围读取ZIP中的指定TIFF成员，避免下载整份大档案。与[另一个六类F3基准](https://zenodo.org/records/3755060)明确区分。
- [Awais与Hanafy初至数据](https://data.mendeley.com/datasets/p8pbnyfybr/1)：Ithra与Yilmaz炮集，CC BY 4.0。实际读取MAT字段后发现没有独立到时标签和时间单位，所以只在实测炮集比较方法分歧；有参考的受控校准另列。也评估了[Hardpicks](https://github.com/mila-iqia/hardpicks)，其跨测区标签体系适合后续扩大研究，但本课选择可轻量摘录的炮集。
- [FORCE2020官方数据记录](https://zenodo.org/records/4351156)及[组织者仓库](https://github.com/bolgebrygg/Force-2020-Machine-Learning-competition)：原始井曲线NLOD 2.0，解释标签CC BY 4.0。孔隙度代理选择有RHOB、DTC、NPHI与单位的井曲线，避免把没有孔隙度标签的速度模型当成同一个目标。
- [OpenFWI](https://openfwi-lanl.github.io/)提供正演地震—速度配对，是研究参照；没有将其速度标签改名为孔隙度。去噪的残差学习参照[DnCNN原论文](https://arxiv.org/abs/1608.03981)，本课重新训练自己的小型网络。

完整下载URL、提交版本、文件SHA256与授权见`assets/seismic/sources.json`。原始大文件保留在被Git忽略的`.artifacts/seismic-data/`。图解不进入训练和评价。

## 三个页面的分工

专业背景有五章：真实背景、技术前沿、示例数据、技术难度与参考方向、术语对照表。现场工位图解释业务，原理图解释物理关系，实际输入窗口介绍观察对象；不在这一页重复网络操作流程。

流程显示01、02、03传统、03智能、04、05六个单元，明确每步输入与交付。智能步骤展开实际网络及参数关系，传统步骤和结果核对使用同一资料。

示范侧重操作后的证据变化：原始输入、常规参照、神经结果、指定参考或去除残差，以及对应的局部波形和统计。结构图解释工作关系，得分表达模型关联，评价只与明确的参考比较。没有从热力图推出地质成因，也没有无计时依据的提速倍数。

样本、切片、阈值、道号、噪声量、正则化参数和观察文本在三个页面之间延续。每例表格都就近区分本课总资料与当前展示窗口；记录切换时图像、得分、波形与导出同时切换。

## 计算、单位和导出

- S1网络门槛只改变网络候选；属性参照门槛单独由检查体3选定并固定，不与不同标度的网络得分共用滑杆。3D得分读取当前体的相邻切片。导出保留源数组起点、体号、切片和体素局部坐标，不声称是地理XYZ。
- S2对外并列全图标签一致率、接受覆盖率和接受区一致率。提高门槛不会提高全图结果。掩膜类号0—9仅对应原解释方案。
- S3同时列出两种方法的覆盖率。平均偏差只对有拾取且有参考的道计算；实测文件缺失参考时显示“无独立参考”。未触发道在CSV中保持空值。
- S4计算`Vp=304800/DTC`（m/s），由深度和声波积分生成有效井段顶部起算的相对双程时，以2 ms重采样，25 Hz Ricker波子生成一维响应；低频阻抗先验使用36 ms高斯尺度。按实际井深位置绘制NPHI曲线，误差单位为百分比点pp。NPHI从未进入输入特征或平滑优化器。
- S4排除缺失或超出DTC 40—220 us/ft、RHOB 1.4—3.2 g/cm³、NPHI 0—0.6的行，只取最长连续有效区间，不跨缺口补值。16/1-2只有较短有效区间，网页显示实际点数。
- S5固定噪声种子后调节真实输入噪声幅值，并重新运行网络。输入、输出和残差满足`输入−输出=残差`。SNR仅相对原F3参考计算。

CSV/JSON导出保存来源、模型SHA256、单位和当前参数。观察文本也保存在导出元数据中。图面可点击；道号滑块和方向键提供同步检查入口。

## 构建和验证

```powershell
python tools/seismic/fetch-data.py
python tools/seismic/prepare.py
node tools/seismic/package-data.cjs
node tools/seismic/rebuild-stage.cjs
node --test tests/seismic.cjs
```

Python准备需要NumPy、Pillow、SciPy、PyTorch、scikit-learn、requests与fsspec；网页端不需要Python或后端。训练固定种子20261102。`provenance.json`保存分组、训练损失、排除规则及发布数据文件的完整性哈希。

模型计算与页面挂载专项测试包括：Python与JS数值对照、整组划分、参数实际改变输入与输出、无参考资料不报成绩、十五页共享资料、资源按案例加载和导出范围。主页面只加载约1.4 KB案例元数据；观察资料在进入对应案例时才载入。
