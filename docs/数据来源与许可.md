## M1 原始RGB与扩充

- 发布方：[nature9420/-ResNet-HMM-Lithology](https://github.com/nature9420/-ResNet-HMM-Lithology)。README明确允许学术使用，其他用途联系作者。
- 固定来源提交：`c5d9fc0c2ab99c983677e3b26c1e523c0d9401ca`。
- 原66张的路径、图片SHA-256、井号、20 m组和划分保存在`tools/m1/runtime/data.js`。
- 新增32张在`tools/m1/expansion/images/`，逐张SHA-256、Git blob SHA-1、来源URL和源标注目录在`tools/m1/expansion/results.json`。它们与原留出组没有井段交集。
- 来源CSV存在乱码。扩充时依据已在原66张核定的标注目录编码、文件名和相同Git blob匹配，不猜测损坏的中文字段。
- SEM成像与RGB成像不同；没有混入Zenodo SEM图像。

## M2/M4 Volve

官方发布方：[Equinor Volve Data Sharing](https://www.equinor.com/energy/volve-data-sharing)。官方允许学术用途；当前官方入口指向需要登录的Databricks Marketplace，本轮没有注册账户或接受额外条款。

本轮实际使用[DrillDash公开整理副本](https://github.com/Sky370/DrillDash/tree/76b94b76efe7eb0d66faabc11305906fd50d8ee8/demo)，固定提交`76b94b76efe7eb0d66faabc11305906fd50d8ee8`。这属于观测记录的派生整理数据，不冒称从官方入口直接取得。保留副本的`DATA-LICENSE.txt`及其归属说明；数据所有者包括Equinor及原Volve合作方。

实际下载文件与哈希：`tools/mudlogging/real-data/manifest.json`。两井深度Parquet及F-1-C分钟观测CSV保存在`real-data/raw/`。原副本将WITSML通道统一为SI后，按推断钻进状态作1 m中位数分箱；这些状态不是地质标签。没有使用其`rop_calc`或虚构地层类别。

| 源通道 | 源单位 | 网页显示 / 换算 |
|---|---|---|
| MD / hole_depth | m | m MD，不当作TVD |
| ROP | m/s | ×3600 → m/h；正值有效钻进时钻时=60/ROP |
| WOB | N | ÷1000 → kN |
| RPM | c/s | ×60 → r/min |
| torque | N.m | ÷1000 → kN.m |
| flow_in | m³/s | ×1000 → L/s |
| TOTGAS | Euc | 保留Euc；不擅自转换为体积分数 |

M4筛选：所有必要通道有限，1<ROP≤300 m/h、WOB>2 kN、RPM≥20、扭矩≥0、流量>0。被排除量逐井记录，井深缺口不补画、不跨缺口平滑。

M2按UTC分钟取中位数，保留每分钟原始点数，不插入缺测分钟。离散泵状态未直接取得，“流量>1 L/s”只作为有循环的派生提示。真实迟到未知；滑块是来源对齐假设，取不晚于目标且相隔不超过1分钟的最近有效记录，超过缺口标为空。

仅F-1-C的M4原始时刻可以跳转到同井M2分钟记录；按已接入资料找两分钟内的最近时刻。F-5不强行连接到另一口井。

## 未取得的真实资料

- [SODIR NOROG Digital Cuttings](https://www.sodir.no/en/diskos/wells/historical-projects/norog-digital-cuttings-project/)介绍确认有白光和UV照片，但本轮未取得具体可复用图像和像素标注。
- [USGS原油荧光图像](https://www.usgs.gov/data/images-two-standard-crude-oils-collected-using-a-fluorescent-camera-device-train-and-optimize)，DOI `10.5066/P1SXVZX2`，记录为CC0；对象是溶于己烷的两类原油，浓度标签不是岩屑像素标签。本轮没有把它换名后用于岩屑分割。
- [Utah FORGE 78B-32日报与日志](https://catalog.data.gov/dataset/utah-forge-well-78b-32-daily-drilling-reports-and-logs)，DOI `10.15121/1814488`，官方目录包含英文日报PDF。它是地热井；本轮只核对目录与语言，没有把它当作Volve同井资料，也没有用中文BiGRU报告英文成绩。

M3真实UV标注与M5真实报告语言适配是后续工作，不能据本轮合成结果声称已经完成。

## 推理组件

ONNX模型由已保存的本课权重导出，模型与原权重哈希见`tools/mudlogging/browser-models/manifest.json`。浏览器使用官方npm包`onnxruntime-web@1.31.1`中的WASM资源，按需载入约14.9 MB，一站共用，不随各案例包重复储存。MIT许可证及下载来源保存在`assets/vendor/ort-1.31.1/`。

运行时只读取静态资源并在浏览器计算。没有预测API、在线训练或业务后端。
