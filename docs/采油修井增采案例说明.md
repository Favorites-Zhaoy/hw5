# 采油、修井、增采教学案例

三个主题各5例，均以“业务问题→传统处理→智能方法→作用依据→结果核对”组织。主题图新生成，保留一张连续原图、图内放大与动效。专业背景有五章，流程按01、02、03传统、03智能、04、05展开，可运行示范直接使用对应记录。三个页签共享记录、参数和观察笔记。

## 证据与复现

每例的来源、授权、单位、分组、模型参数与三条独立Python推断参考在`assets/operations/data/{id}.json`。`assets/operations/provenance.json`记录最终文件SHA256与固定检验范围；图解不进入训练。所有案例数据按需载入，首页不下载15个完整数据包。导出保留原输入、原观测、来源ID、单位、参数、模型SHA与当前结果。

代码快照在`tools/operations/source-data/{production,workover,eor}/`，各有原URL、许可和SHA索引；删去BSEE原文短片段，保留用于计算的事实术语。准备脚本使用这些最小快照，已在无研究缓存的目录复现。原始大型下载、研究缓存和桌面截图保留本地，不进入网页载入路径。

```sh
python -X utf8 tools/operations/prepare-production.py
python -X utf8 tools/operations/prepare-workover.py
python -X utf8 tools/operations/prepare-eor.py
npm run operations:build
node --test tests/operations.cjs
```

训练工具需要Python、NumPy、SciPy、scikit-learn和PyTorch；网页只用原生JavaScript前向推断、几何与约束求解。运行网页不依赖Python、模型服务或第三方API。预览需静态HTTP服务器。

神经网络、GP、CRM、知识约束、文本相似度与PCA均对照独立Python参考。测试还检查因果时间窗口、未来目标隔离、约束满足、45个页签挂载、跨页状态、失败重试、导出与弱结果保留。视觉与交互只检查桌面浏览器。

## 保留的弱结果

示功图CNN和Volve GRU未超过对应简单参照；真实跨井PCA默认门槛漏检；化学驱逐浓度留出GP与陌生CSS项目均未胜过参照。修井GRU未胜过上次值，CHECK误差范围在TEST计划中只覆盖42.9%。这些结果保留在页面，不能用演示样品或模拟成绩替换。
