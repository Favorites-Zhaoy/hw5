# 运输、加工教学案例说明

两个主题各5例，保留TXT与现有`assets/data.js`的案例编号和方法分类。原生“专业背景、案例流程、可运行示范”三页共享当前记录、参数和观察笔记；流程统一为01、02、03传统、03智能、04、05。

业务总览和工位图只作插图，不进入训练，也不充当观测或标签。T5读取的是真实照片像素；T2的检测灰度图则是明确声明的受控数据，两者都与业务插图分开。

## 来源、样本范围与现有结果

以下均取自当前10个payload的`validation`，不重新训练或挑选成绩。准确率越高越好，MAE与代理能耗越低越好；不同任务的数值不能横向排名。

- **T1：受控事件与定位。** [GPLA-12](https://github.com/Deep-AI-Application-DAIP/acoustic-leakage-dataset-GPLA-12)实测压缩空气声学资料只作背景，其12类全部属于泄漏采集条件，没有正常类或位置真值。主实验独立生成180段，按120／24／36段划分。36段留出中，规则准确率**83.33%**、GRU **80.56%**，GRU较弱；12段受控泄漏的定位MAE为互相关**6.64m**、到时参照**12.24m**。这些数值依赖已知波速与同步假设，不是现场精度。
- **T2：坐标模板与独立减薄模拟。** [Zenodo缺陷资料](https://zenodo.org/records/10809418)为CC BY4.0坐标地图，没有实测厚度或时间。派生灰度图以地图2的96张图留出：灰度规则**64.58%**、CNN **96.88%**。另按完整轨迹留出的120个壁厚目标，末值MAE **0.2665mm**、GRU **0.0462mm**。图像与轨迹的展示配对不代表现场缺陷匹配；4mm阈值不是安全规范值。
- **T3：公开网络的声明代理。** [GasLib-11](https://gaslib.zib.de/testData.html)为CC BY3.0人工测试网络。本课只借用两站编号与流量边界，并显式改成并联代理，未求解原11节点全网。7个预设情景中6个可行，平均代理能耗为均分**1588.38kW**、优化**1523.00kW**；保留不可行情景和缺口。这是代理目标比较，没有现场节能验证。
- **T4：稀疏标定受控记录。** [NIST流量标准资料](https://www.nist.gov/publications/gas-flow-standards-and-their-uncertainty)只提供校准原理背景。30段训练、12段留出，每段120min、每25min开放参考；1380个非标定时刻的MAE为最近偏差保持**0.7533m³/h**、Kalman **0.4535m³/h**。连续真值仅供评价，不能补进非标定时刻的输入，也不构成计量认证。
- **T5：真实透明容器照片。** [Glasses-in-the-Wild](https://zenodo.org/records/17288503)，CC BY4.0。310张照片按拍摄时段分为227／15／68张；68张留出的液面行MAE为边缘参照**25.69px**、CNN **23.95px**，按原256px尺度计。**透明饮用容器实验不是储罐现场精度**，没有罐区泄漏或雷达真值；同一参与者资料也不等于整容器或跨油库留出。高度比例不能直接当作体积比例。
- **R1：原创馏分分割方程。** [IDAES示例](https://idaes-examples.readthedocs.io/en/latest/docs/flowsheets/hda_flowsheet_with_distillation_doc.html)仅作约束建模背景。本课1080条受控样本按进料组分为720／120／240条。240条留出的归一化响应误差为解析参照**0%**、MLP **3.349%**；解析方程正是标签生成规则，因此零误差不是实测结论。代理候选仍需解析复核，不能称为工业常减压模型或真实节能收益。
- **R2：公开FCC流程模拟。** [ML-PSE FCCU](https://github.com/ML-PSE/Fluid-Catalytic-Cracking-Unit-Dataset-for-Process-Monitoring-Evaluation)，MIT。保留分钟顺序，变进料前4天训练、第5天验证、后2天测试，另留整条稳进料轨迹。时间留出576个目标的五产品平均MAE为基线**0.02271个百分点**、GRU **0.08721个百分点**；另一轨迹569个目标分别为**0.02123／0.07931个百分点**，GRU均较弱。LN、HN是石脑油，不证明成品汽油达标；没有干气标签，不补造收率。
- **R3：真实轴承试验台。** [Zenodo 7589904](https://zenodo.org/records/7589904)，CC BY4.0，8569条记录。只用第一状态时间前段训练，正常后段171个目标的MAE为基线**9.707×10⁻⁶m/s**、GRU **1.515×10⁻⁵m/s**，GRU较弱；其他润滑／密封状态不参与训练或定门槛。源文件无真实日期，只有名义2min间隔；评价每4个源点取一次，不能把连续触发点数直接换成固定时长。没有RUL证据，也不是炼厂故障验证。
- **R4：原创受控审核语料。** [否定范围研究](https://pubmed.ncbi.nlm.nih.gov/12123149/)仅作方法背景。384条中英文本按表达家族划分为240／48／96条；未见表达家族的断言准确率为基线**33.33%**、MLP **56.25%**。这是文字断言分类，**识别“未超限”等否定表述不代表产品合规**。数值矛盾仍需保留；审核线、风险、工时和人员容量均为教学假设，不是法规或产品放行条件。零匹配、低分和未分配任务也应显示。
- **R5：公开29日合成示例。** [Kim与Kwon开源资料](https://github.com/Danny-Taehyun-Kim/debutanizer-hybrid-model)，MIT，作者明确没有真实厂测。三日窗形成18条训练、4条验证、5条末段降负荷测试；测试MAE为当前工况Ridge **1.2063kgf/cm²**、GRU **0.5591kgf/cm²**。仅5个测试日，日期排列不证明真实过程动力学，更不支持产品放行或跨装置部署。

## 证据文件与复现

`assets/downstream/data/{t1…t5,r1…r5}.json`保存原输入、独立参考、基线、模型参数、固定评价范围及Python推断参考。T2同时保存CNN与`secondaryModel`壁厚GRU；校验和导出应覆盖两者。页面改门槛、波速、约束或文本后，应记录当前参数和重新计算结果，不能拿固定验证成绩冒充新情景成绩。

中文内容与来源边界见`tools/downstream/content-{transport,refining}.json`和`research-{transport,refining}.json`。最小输入在`tools/downstream/source-data/{transport,refining}/`，各自`source-index.json`记录原URL、许可和SHA。运输索引区分必需输入与仅作研究证据的文件；加工快照保留MIT／CC BY4.0许可及源单位。最终打包可改变JSON序列化与模型SHA字段，准备阶段的整文件哈希不应冒充最终发布哈希。

在项目根目录、具备所需Python依赖的环境中运行：

```sh
# 运输：案例编号使用位置参数；省略时准备全部5例。
python -X utf8 tools/downstream/prepare-transport.py
python -X utf8 tools/downstream/prepare-transport.py t1 t3

# 加工：部分重建使用 --cases；省略时准备全部5例。
python -X utf8 tools/downstream/prepare-refining.py
python -X utf8 tools/downstream/prepare-refining.py --cases r2 r5

# 模型数据准备完毕后，生成运输／加工内容、原生页面与最终完整性记录。
node tools/downstream/build.cjs

# 项目现有回归检查；运输／加工专项命令可由维护者继续补充。
npm test
```

上述命令是复现入口，不表示本说明编写时重新执行过训练或全部测试。不要为了提高留出成绩反复按测试结果选模型；保留弱于基线和不可行的结果。
