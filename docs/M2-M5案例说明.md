# M2—M5 教学案例说明

2026-11-01。五部分背景和六步流程沿用M1的组织方式；本次只检查桌面。四例的图、分组、指标与可导出的记录共用一份固定实验。机理图为原创SVG示意，未挪用论文的实验图片或性能数字。

## 数据与结果

| 案例 | 分组与实际模型 | 固定常规参照 | 留出结果 |
| --- | --- | --- | --- |
| M2 气测 | 30口模拟井×96点，20/4/6口；6通道因果CNN | 全烃超过前12点中位数的2倍，结合对齐泵状态的窗口 | 宏平均F1：86.9% → 100.0%，576点 |
| M3 荧光 | 30盘×4图，20/4/6盘；两级U-Net | 共同曝光校正与ROI内的固定RGB阈值 | 汇总IoU：60.2% → 95.0%，24图 |
| M4 钻时 | 30口模拟井×128点，20/4/6口；5通道扩张CNN | 4.1、6.7 min/m阈值，两种方法均作4点最短段过滤 | ±2 m层界匹配F1：67.7% → 100.0%，29个生成层界 |
| M5 摘要 | 1152/80/160条，按32/8/16个句式组；字符BiGRU | 按接单根、气测、钻时的字面词优先匹配 | 事项宏平均F1：28.6% → 74.5%；模型分错41/160条 |

这里的100%是实际计算出的合成资料成绩。生成规则较简单，同一生成分布内的模拟井不能代替现场独立井。检查组也全部保留：M5的宏平均F1由规则的63.3%降至BiGRU的43.3%，说明句式迁移仍不稳定。没有根据留出结果重新调参，没有人工效率、专家准确率或现场推理耗时测评。

M2的6 min迟到为教学设定，仅泵状态按此对应到返出时刻；排量和钻速仍为当前工况通道。M3的荧光输入、掩膜与曝光参照均为生成器绘制，目标面积占ROI的比例不代表含油量。M4的三类是合成可钻性段，不是岩性鉴定。M5只用模型分类语句，井段、峰值、岩性描述、钻井液密度和原始摘录由同一记录ID关联，摘要为确定性模板，不含自由生成的地质判断。

M3/M5初始选择用于讲解规则漏判的例子；完整下拉列表、错例入口与所有留出记录导出均可使用，汇总指标始终包含全组。交互分割阈值和层界容差只改变当前留出组的后处理，检查组保持固定设置。

## 复现与来源记录

- `tools/mudlogging/prepare-experiments.py` 固定随机种子、超参数、规则参照及组别；训练轮数为M2 100、M3 55、M4 120、M5 32。
- `tools/mudlogging/checkpoints/` 保存实际PyTorch权重，`experiments/` 保存留出得分、预测、标签和原图。源文件及权重SHA-256写入各案例的 `provenance.json`。
- `tools/mudlogging/verify-experiments.py` 直接载入权重，不重新拟合。复算的四例最终候选与保存结果完全相同，M3量化像素得分逐字节相同；M2/M4源通道已四舍五入，得分最大差异约0.0001。
- M5额外的岩性描述和钻井液密度由构建器根据记录ID确定，未加入分类输入，不更改模型指标。构建器哈希也记录在 `provenance.json`。
- 三个章节文件互相独立；外壳只接受已挂载子页面的样本和导航消息。原M1旧入口屏蔽规则保留。
