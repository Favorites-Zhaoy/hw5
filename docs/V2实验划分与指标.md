# V2 实验划分与指标

当前为V2.0.2，按总览既定领域选型：CV为M1/M3，TS为M2/M4，NLP为M5。旧版检查点为`lesson-v1.1.0`；新工作由`codex/v2-experiments`合并至`main`发布。

## 可执行层级

| 案例 | 浏览器实际重算 | AI执行方式 |
|---|---|---|
| M1 | RGB权重、距离上限、全部基线候选与矩阵、井段错误率 | 原CNN及扩充实验为固定回放 |
| M2 | 真实/合成阈值候选、迟到来源对应、历史长度、合成规则指标 | 真实GRU按顺序读取此前最多12分钟六通道，实际计算下一分钟预测及残差；合成因果时序卷积可在WASM重跑 |
| M3 | 曝光、共同校正、颜色规则、ROI、阈值、逐像素面积/IoU | 真正运行U-Net ONNX；输入改变而未运行时不显示新的AI掩膜 |
| M4 | 变化阈值、分段平滑、历史长度、工况扰动、候选与证据 | 真实LSTM沿井深读取此前及当前最多12条工况，实际计算ROP与残差；合成时序卷积可在WASM重跑 |
| M5 | 否定规则、字段抽取、冲突、置信阈值与摘要 | 修改中文原句实际运行BiGRU；摘要由字段组织，不是LLM自由生成 |

原输入和冻结基准保持不变，改变后的单份输入不会偷偷混入原留出汇总。导出包含资料性质、来源、参数、模型/规则版本、运行方式和待确认状态。

## M1：同一24张历史留出照片

| 固定实验 | 拟合原图 / 视图 | 一致数 | 一致率 | 宏平均F1 |
|---|---:|---:|---:|---:|
| 原始ResNet-18特征＋分类层 | 42 / 42 | 8/24 | 33.3% | 0.274 |
| 扩充同源RGB | 74 / 74 | 8/24 | 33.3% | 0.296 |
| 扩充＋0.8/1.2倍曝光增强 | 74 / 222 | 10/24 | 41.7% | 0.351 |
| 原始固定颜色基线 | 42张参考 | 14/24 | 58.3% | 原实验定义 |

新增32张均避开原留出20 m组。三次CNN保持同一ImageNet编码器、中心72%裁切、224输入、标准化及平衡多类Logistic分类层（C=1、seed42）。增强只用于拟合，设置不由测试成绩选择。原数据曾在历史版本展示，因此不是新盲测，更不是跨井结果。新增样本和增强仍未超过颜色基线。

## M2

合成部分保留30口井按20/4/6整井划分；576个留出点的宏平均F1为规则0.8694、CNN1.0000。迟到错配按钮把输入改为0 min再真正重跑，固定压力检查中6口井分别出现7、4、3、4、4、5个模型错误；这些是输入错配试验，不是新现场性能。

真实F-1-C分钟记录无事件真值。当前GRU以此前最多12分钟的TG、流量、WOB、RPM、扭矩和ROP，预测当前六个标准化通道；当前观测不进入本次输入。单层单向GRU，隐藏维12，线性输出6维；seed1722、120轮、Adam 0.004，固定设置没有按验证或测试成绩选择。

在2013-08-22至26拟合，27日验证，28日留出；标准化只用拟合日期。窗口在缺失分钟处断开，不插值；首条或断点无历史时明确不预测。7007个可预测拟合点、1421个验证点、351个留出点。每次先独立运行有序窗口，避免读取后续观测。阈值参照训练预测残差P95。

留出六通道标准化预测RMS平均为0.1473，沿用上一分钟的参照为0.03749；验证相应为0.1660 / 0.03730。当前小模型没有预测误差优势，页面保留这一结果；没有事件标签，不报告异常识别F1。旧单时刻自编码器及权重保留在原`m2.json`，当前页面使用`m2-gru.json`。

合成CNN回放始终标明原始6 min输入；改变对齐参数后，点击运行才把新输入送入模型，不把换图当作重跑。

## M3

30盘×4图=120张64×64合成RGB，按盘隔离为80/16/24。原实验逐像素汇总：规则TP4885、FP0、FN3225，IoU0.6023；U-Net TP7968、FP280、FN142，IoU0.9497。模型改善漏圈，同时新增多圈。

当前单图的ROI、曝光和概率阈值改变后单独计算，原24张冻结实验保持原定义。没有真实岩屑UV与独立像素标注，不报告“真实IoU”。亮区比例不换算为含油饱和度。

## M4

真实ROP主流程为LSTM工况序列回归：沿测量井深读取此前及当前最多12条WOB、RPM、扭矩和流量记录，输出当前logROP，再取指数还原钻速。当前或历史ROP不进入输入。窗口超过2 m缺口就断开，起点使用已有较短窗口，不补画或引入未来数据。单层单向LSTM、隐藏与记忆维各12、线性输出1；seed1724、180轮、Adam 0.004，固定设置未按验证或测试成绩选择。

F-1-C前794点拟合、后265点验证，F-5全823点留出，沿用原划分。每个窗口从零状态依次读取，记录块之间通过显式来源上下文延续过去记录。页面展示真实历史输入与逐步隐藏状态，历史长度和钻压比例均进入实际计算。LSTM验证MAE为7.97 m/h。

| 同一F-5整井留出 / 823点 | ROP MAE（m/h） |
|---|---:|
| LSTM序列回归（当前主流程） | 28.59 |
| 随机森林（历史单点对照） | 34.81 |
| 旧MLP 4→24→24→1、360轮 | 47.56 |
| 训练井ROP中位数24.43 m/h的常数参照 | 26.14 |

LSTM仍高于常数参照，不能宣称在该井最优。旧模型与原文件保持不变；当前模型在`real-data/m4-lstm.json`，包含原始文件与脚本哈希、拟合/验证/测试ID和实际PyTorch核对输入。变化候选没有独立地质标签，不报告层界F1。传统钻时变化阈值和模型logROP残差变化阈值使用各自单位；输入扰动不改写原始留出成绩。

原30口合成井CNN实验单独保留，训练20、验证4、留出6；其±2 m边界F1为规则0.6769、CNN1.0000，只适用于生成器标签。

## M5

1392条中文合成语句：1152条/32模板族拟合，80条/8族验证，160条/16族留出。换数字不算新句式。原留出宏平均F1为规则0.2857、BiGRU0.7451，41条模型错误保留；验证组BiGRU还低于规则，不能只展示一组胜出成绩。

字嵌入24→双向GRU24×2→4类。浏览器按训练词表编码，最多96字符；batch=1、不填充的前向与原packed GRU逐条核对。修改后语句无独立真值。缺失数值留空，冲突数值不擅自挑一个写入摘要；原附表字段和编辑后提取片段分别可定位。

## 复现与核对

```powershell
npm ci --ignore-scripts
npm run build
npm test
python tools/mudlogging/verify-experiments.py
python tools/preview-static.py --port 8765
```

自动检查包含领域分配、GRU/LSTM实际门计算与PyTorch核对、全部8822条气测与1882条钻进记录、无未来泄漏、顺序敏感、历史长度与导出一致性。原随机森林、MLP、自编码器及四个合成实验的检查继续保留；真实/合成资料切换时标题、流程、方法图和算法身份同步。DOM测试不替代桌面视觉验收。

当前TS模型复现：`python tools/mudlogging/prepare-sequence-models.py`，随后`npm run build`。脚本从已固定的原`m2.json`、`m4.json`读取观测，不覆盖历史模型。原`prepare-experiments.py`及原权重不改写。

ONNX导出已核对6个M2、24个M3、6个M4和160个M5留出输入，ORT CPU与原PyTorch最大logit绝对误差小于3×10⁻⁵。Chrome 156在隔离iframe中完成5项WASM核对（原图、曝光改变、原句、编辑原句、分类错例），最大概率误差约1.01×10⁻⁶。
