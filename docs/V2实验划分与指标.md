# V2 实验划分与指标

本轮为V2首轮实现。旧版检查点为`lesson-v1.1.0`，新工作在`codex/v2-experiments`，尚未替换线上`main`。

## 可执行层级

| 案例 | 浏览器实际重算 | AI执行方式 |
|---|---|---|
| M1 | RGB权重、距离上限、全部基线候选与矩阵、井段错误率 | 原CNN及扩充实验为固定回放 |
| M2 | 真实/合成阈值候选、迟到来源对应、合成规则指标 | 真实自编码器展示当前记录的实际六通道重构；候选使用保存残差；合成因果CNN可在WASM重跑 |
| M3 | 曝光、共同校正、颜色规则、ROI、阈值、逐像素面积/IoU | 真正运行U-Net ONNX；输入改变而未运行时不显示新的AI掩膜 |
| M4 | 变化阈值、分段平滑、工况扰动、候选与证据 | 真实随机森林遍历100棵树，当前记录的分支可查看；合成CNN可在WASM重跑 |
| M5 | 否定规则、字段抽取、冲突、置信阈值与摘要 | 修改中文原句实际运行BiGRU；摘要由字段组织，不是LLM自由生成 |

原输入和冻结基准保持不变，改变后的单份输入不会偷偷混入原留出汇总。导出包含资料性质、来源、参数、模型/规则版本、运行方式和待确认状态。

## M2

合成部分保留30口井按20/4/6整井划分；576个留出点的宏平均F1为规则0.8694、CNN1.0000。迟到错配按钮把输入改为0 min再真正重跑，固定压力检查中6口井分别出现7、4、3、4、4、5个模型错误；这些是输入错配试验，不是新现场性能。

真实F-1-C分钟记录无事件真值。自编码器结构6→12→3→12→6，在2013-08-22至26拟合，27日保留验证，28日保留检查；标准化只用拟合日期。输入为真实TG、流量、WOB、RPM、扭矩和ROP，阈值参照训练残差P95。自编码器只提示少见通道组合，不报告现场F1。

合成CNN回放始终标明原始6 min输入；改变对齐参数后，点击运行才把新输入送入模型，不把换图当作重跑。

## M3

30盘×4图=120张64×64合成RGB，按盘隔离为80/16/24。原实验逐像素汇总：规则TP4885、FP0、FN3225，IoU0.6023；U-Net TP7968、FP280、FN142，IoU0.9497。模型改善漏圈，同时新增多圈。

当前单图的ROI、曝光和概率阈值改变后单独计算，原24张冻结实验保持原定义。没有真实岩屑UV与独立像素标注，不报告“真实IoU”。亮区比例不换算为含油饱和度。

## M4

真实ROP主流程改为随机森林回归：输入WOB、RPM、扭矩、流量四个表格字段，输出logROP。F-1-C的1059个有效点中，前794点拟合、后265点验证；F-5整口823点留出，沿用旧MLP的同一划分。100棵树、最大深度5、每叶至少8点、bootstrap、seed1724；每个分裂考察全部4个字段。设置按教学任务预先固定，没有用F-5结果选择超参数。

浏览器把四个物理量转换为float32，按各棵树的阈值逐节点计算，平均logROP后取指数还原ROP。这不等于对各树ROP作算术平均。第1棵树的实际路径与全部100棵树的最终输出分别显示，随井深光标、钻压比例更新。验证MAE为7.91 m/h。

| 同一F-5整井留出 / 823点 | ROP MAE（m/h） |
|---|---:|
| 随机森林（当前主流程） | 34.81 |
| 旧MLP 4→24→24→1、360轮 | 47.56 |
| 训练井ROP中位数24.43 m/h的常数参照 | 26.14 |

随机森林低于旧MLP，仍高于常数参照，不能宣称在该井最优。旧模型与原文件保持不变；新模型在`real-data/m4-forest.json`，包含原始文件哈希、逐条拟合/验证/测试ID及旧MLP指标。变化候选没有独立地质标签，不报告层界F1。传统钻时变化阈值和模型logROP残差变化阈值使用各自单位；输入扰动不改写原始留出成绩。

原30口合成井CNN实验单独保留，训练20、验证4、留出6；其±2 m边界F1为规则0.6769、CNN1.0000，只适用于生成器标签。

## M5

1392条中文合成语句：1152条/32模板族拟合，80条/8族验证，160条/16族留出。换数字不算新句式。原留出宏平均F1为规则0.2857、BiGRU0.7451，41条模型错误保留；验证组BiGRU还低于规则，不能只展示一组胜出成绩。

字嵌入24→双向GRU24×2→4类。浏览器按训练词表编码，最多96字符；batch=1、不填充的前向与原packed GRU逐条核对。修改后语句无独立真值。缺失数值留空，冲突数值不擅自挑一个写入摘要；原附表字段和编辑后提取片段分别可定位。
