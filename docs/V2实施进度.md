## V2.0.2：先遵守总览的领域分配

录井总览已有分配：CV＝M1、M3，TS＝M2、M4，NLP＝M5。V2.0.1将M2、M4改为单时刻组合和单点回归，未体现其TS任务。本版修正主流程；生成器会核对方法所属领域与总览字段是否一致，分配不符时停止生成。

| 领域 | 案例 | 当前方法与实际输入 |
|---|---|---|
| CV | M1 岩屑识别 | 冻结ResNet-18＋分类层，读取RGB照片 |
| CV | M3 荧光区域 | U-Net，输出逐像素区域 |
| TS | M2 气测异常 | 单向GRU，读取当前分钟之前最多12条连续六通道记录，预测下一分钟 |
| TS | M4 钻进响应 | 单向LSTM，沿井深读取最多12条四通道工况，估计当前ROP |
| NLP | M5 交班记录 | BiGRU语句分类＋有来源的字段模板 |

M2与M4已训练实际序列权重，页面执行GRU/LSTM门计算；没有借用合成CNN输出。流程图显示有序输入窗口与逐步隐藏状态，历史长度可调，窗口、结果与导出同步变化。M2缺测分钟断开；M4超过2 m的深度缺口断开，深度顺序不冒称等时间间隔。

保留同一来源观测与原划分：M2按日期；M4仍为F-1-C的794/265点拟合/验证，F-5全823点留出。LSTM留出MAE 28.59 m/h，仍高于常数参照26.14；M2留出标准化预测RMS 0.147，高于沿用上一分钟的0.037。这些结果保留，不用异常候选数量证明模型更准。旧AE、MLP、随机森林和合成时序卷积留在历史实验资料中，当前真实数据主流程仅展示GRU/LSTM。

125项自动检查通过，覆盖领域分配、实际PyTorch输出、全部记录的浏览器前向、无未来泄漏、顺序敏感、历史参数与导出一致性。桌面浏览器核对GRU与LSTM窗口交互；此前未完成的Edge验收仍单独保留。

## V2.0.1：历史变更

| 案例 | 当前主流程 | 选择理由 |
|---|---|---|
| M1 岩屑岩性辅助识别 | 冻结ResNet-18特征＋分类层 | RGB整图分类，标签少，保留卷积纹理表征 |
| M2 气测异常 | 六通道自编码器 | 真实资料没有事件标签，学习常见组合并比较重构残差 |
| M3 荧光区域 | 小型U-Net | 有像素标签，需要保留目标位置和边界 |
| M4 钻进响应 | 随机森林回归＋残差变化规则 | 四个工况字段的表格回归，可展开实际分支 |
| M5 交班记录 | BiGRU事项分类＋字段模板 | 用语句前后文归类，数值仍绑定来源 |

背景方法卡、流程标题、六步说明、原生SVG结构图、注册摘要与导出身份同步更新。M2逐通道对照真实观测和重构值；M4展开当前输入经过第1棵树的路径，最终输出仍由全部100棵树计算。原合成CNN明确标注为独立对照，切换资料时一起切换说明和图示。

随机森林沿用原MLP划分与全部原始传感器，在F-5上MAE 34.81 m/h，低于旧MLP 47.56，仍高于常数参照26.14。页面保留这一限制。122项自动检查通过，本轮另在桌面IAB核对了M2资料切换、M4钻压与井深联动；此前Edge未完成的状态不改写为通过。
