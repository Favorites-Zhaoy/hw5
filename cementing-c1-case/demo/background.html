01 / PROFESSIONAL BACKGROUND

把胶结波形放回井深，才能读懂水泥环。

套管外的水泥环需要黏住套管并隔开不同地层。声波测井提供的是胶结线索；先分清波形、幅值与隔离能力，再对同一井段比较两种读法。

01CONTEXT

真实背景

水泥浆进入套管与井壁之间的环空，凝固后形成水泥环。胶结缺陷可能留下窜流通道；某一条声波曲线不能独立证明所有方向上的液压隔离。

自由套管中的早到套管波通常较强；胶结使能量向外耦合并衰减。CBL压缩为幅值曲线，VDL把随传播时间变化的波列沿井深铺开，方便检查连续性与后续到波。

05GLOSSARY

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
水泥环 / Cement sheath套管外凝固后的水泥层。本课的评价对象。
环空 / Annulus套管与井壁之间的空间。水泥需要连续填充的位置。
CBL / 胶结测井利用套管声波衰减判断胶结线索。传统基线输入，mV。
VDL / 变密度测井把声波波列沿井深排列成图。3×24深度图块。
套管波 / Casing arrival沿钢套管传播的较早到波。早时窗纹理。
地层波 / Formation arrival声能耦合到外部后形成的到波。较晚波列的概念线索。
微环隙 / Microannulus套管与水泥界面的细小间隙。未显式模拟的干扰因素。
增益 / Gain测量信号被整体放大的程度。可修改的输入扰动。
MLP / 多层感知机组合多个输入的前馈神经网络。75→12→3，实际拟合。
混淆矩阵 / Confusion matrix把参考类与预测类交叉计数。显示分错到哪一类。
拟合组 / Fit groups用来学习权重、标准化尺度的模拟井或作业。整组隔开，不能把同一井相邻点随机分到两边。
保留组 / Held-out groups训练之前就隔开的另一组资料。只检查泛化，不能用其标签挑模型。
合成资料 / Synthetic data由公开脚本和固定种子生成的教学资料。有可复算的标签，但不证明现场有效。
