# 石油勘探开发的智能化可能性地图

可视化导论课程项目初版。以 13 个石油作业环节、61 个候选场景为目录，把专业背景、案例流程和浏览器内交互演示连接起来。

## 运行

在线访问：[课程网站](https://favorites-zhaoy.github.io/hw5/)；[M1案例流程](https://favorites-zhaoy.github.io/hw5/#/scene/m1?case=m1-cuttings-preview-local&tab=flow)。

下载或克隆仓库后，使用 Chrome 或 Edge 打开根目录的 `index.html`。无需安装依赖或启动后端。

如需 HTTP 预览，可在此目录运行 `python -m http.server 8080 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8080`。

## 首页

- 用户提供的油田摄影封面，搭配明亮朱红色主题。
- 动态河流场景地图：红色流光沿弯曲主河道穿梭，阶段节点与两岸场景通过支流相连；支持搜索、案例筛选、悬停高亮和动效暂停。
- 五类方法探索器，支持点击和方向键切换。
- 环节 × 方法矩阵，可切换候选场景分布与案例覆盖。
- “读懂专业背景 → 拆解案例流程 → 运行交互演示”学习入口。

## 案例接入

录井环节（`#/stage/mudlogging`）使用用户提供的现场图解，叠加原生 SVG 流动箭头、信号曲线、图像扫描和荧光动画。选择 CV 放大 m1/m3，TS 放大 m2/m4，NLP 放大 m5；点击图画进入原有场景讲解，已导入的案例仍由注册表自动展示。支持动效暂停、键盘操作和小屏放大图卡。图解是导航与教学示意，五个完整案例仍需各自接入。

保留原门户的案例包协议。点击“添加案例”，选择解压后的案例文件夹，或多选包内文件。上传器支持整页 HTML、JS 模块和复用内置演示三种形式。

`firstbreak-pick-case/` 是原格式初至波案例包，可以直接导入。`assets/cases/` 中包含原模板及默认测井案例。详细字段见 [接入指南](docs/如何添加新案例.md)。

m1 岩屑岩性辅助识别案例已接入 `#/scene/m1`，包含专业背景、案例流程和可视化示范；三部分均有可视化。直接打开 `m1-cuttings-case/demo/index.html` 可独立学习完整案例，也可通过“添加案例”导入整个文件夹。采用 66 张公开 RGB 岩屑原图，按 20 米井段分组为 42 张训练图与 24 张测试图，在浏览器中实际提取 34 维手工视觉特征（RGB直方图、Uniform LBP、梯度方向和统计量），使用kNN监督分类。先在训练集内部按井段留一组交叉验证，锁定参数后才开放测试集。可检查相似样本、混淆矩阵、光照敏感性、人工复核与CSV导出。公开教学子集在历史版本中已展示，不宣称独立盲测；单井分数不代表新井效果。数据仅按上游学术用途说明用于课程；来源、逐样本校验值和方法边界均在案例包中。页面保留暖米色立体插画风格，插画不作为训练数据。

可提交文件夹为 `m1-cuttings-case/`；当前压缩包为 `submissions/m1-cuttings-case-v1.5.0.zip`，解压后按原协议导入。入口 `demo/index.html` 已内嵌样式、脚本、数据与插画。核心主题与大图样式分离，随正文保留以适配只保留 body 的预览入口；完整交互建议在 Edge 或 Chrome 中直接打开。专业背景按老师示例的“当前做法与问题、AI 能做什么、需要准备什么、难度与参考方向”四项重组，加入岩性描述依据、迟到对应、混样与跨井验证条件，保留岩性结构与迟到参数交互；“人工描述的依据”加入四篇已发表研究的真实岩屑、粗细粒薄片、胶结和页岩结构图，可点击展开，图号、比例尺、出处与许可均保留；案例流程以专业术语为主标题、通俗解释为副标题，拆为七步，包含实际井段分组、RGB区间像素定位、Uniform LBP圆周采样、距离分解、逐票计数和分阶段评估；门户的三个标签页也分别挂载对应的完整内容。独立预览被窗口嵌入时不会隐藏前两部分。可编辑源文件保留在 `tools/m1/`，其中 `background.template.html` 为专业背景页面、`background-metadata.cjs` 为旧规范的四节内容；源码修改后运行 `node tools/build-m1-case.cjs` 重建案例页、清单与门户注册文件；运行案例本身不需要此工具。

上传记录保存在当前浏览器的 `localStorage`，不会写回源码目录。换浏览器或电脑时需要重新导入；提交作业时请保留完整案例包。

## 在线部署

GitHub Pages从`main`分支根目录发布，`.nojekyll`让HTML、JavaScript和案例资源按静态文件提供。推送到`main`后自动部署；使用哈希路由，M1等场景链接可以直接分享。

在线网站的案例导入仍保存在当前浏览器，不能作为全班共享上传服务。源码和提交包保留在仓库中，可继续下载离线运行。

## 检查

安装 Node.js 后运行：

```sh
node --test tests/regression.cjs tests/m1-preview.cjs
```

测试使用内存存储与 DOM 模拟，覆盖旧包导入、演示挂载、旧存档恢复、场景字段保留、路由行为、河流几何、筛选重排、动效开关与资源清理；不能替代真实浏览器的视觉检查。河流采用原生 SVG 与 CSS 动画，系统偏好减少动态效果时默认暂停。

封面图片由项目使用者提供，原始像素保留在 `assets/images/oilfield-cover.png`，页面通过 CSS 校正方向。
