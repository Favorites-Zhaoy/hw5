# 智探油气 · 石油勘探开发智能化探索

可视化导论课程项目初版。以 13 个石油作业环节、61 个候选场景为目录，把专业背景、案例流程和浏览器内交互演示连接起来。

## 运行

在线访问：[课程网站](https://favorites-zhaoy.github.io/hw5/)；[M1案例流程](https://favorites-zhaoy.github.io/hw5/#/scene/m1?case=m1-cuttings&tab=flow)。

下载或克隆仓库后，使用 Chrome 或 Edge 打开根目录的 `index.html`。无需安装依赖或启动后端。

如需 HTTP 预览，可在此目录运行 `python -m http.server 8080 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8080`。

## 案例接入

m1 岩屑岩性辅助识别案例已接入 `#/scene/m1`，三页为“专业背景、案例流程、可运行示范”。专业背景按真实背景、技术前沿、示例数据、技术难度与参考方向、术语对照表组织，用现场过程、岩石结构示意、近期研究机制图配合真实照片。技术前沿引用 Zhang 等（2026-10）、Hou 等（2026-05）与 Olsen 等（2025）的研究，分别解释注意力、多任务学习和基础 ResNet-18。

案例流程以井 2 的 66 张照片设定批次任务，限定六步：设定场景 → 准备图像与标签 → 按井段划分 → 从传统观察到 CNN 分类 → 比较常规与 AI 结果 → 形成井深记录。第四、五步重点讲算法接替什么、怎样处理、实际效果如何。

可运行示范把同一组原图和 CNN 候选逐张对应，可回放固定实验的整批输出。井深图同时展示源记录、常规颜色参照和 CNN，联动原图、三类得分、类别响应并支持 CSV 导出。播放时间不代表推理耗时。

当前提交文件夹为 `m1-cuttings-case/`，压缩包为 `submissions/m1-cuttings-case-v3.0.2.zip`，解压后按原协议导入；直接打开 `demo/background.html`，其余两页为 `demo/workflow.html` 与 `demo/identify.html`。请保留完整文件夹，三页共用本地 assets 中的样式、脚本、原始图像与实验记录。样品选择会在三页之间延续，切换页面时回到章节开头；支持导出数据清单和当前组识别记录。

识别采用 ImageNet 预训练的 ResNet-18，冻结卷积层，只拟合三类线性分类层。中心 72% 裁切后缩放为 224×224。开发用 42 张照片按 12 个井段组逐组留出，另有 24 张照片分为 5 个留出组；每折的缩放参数和分类层只用该折开发资料拟合。页面展示已经计算并保存的结果及逐类别 Grad-CAM，不在浏览器里重新训练或运行网络。实际开发组一致率 88.1%，留出组 33.3%；保留全部差异，不用论文性能替代本例结果。这是曾在旧版展示过的单井公开教学子集，不能声称独立盲测或新井效果。

新增固定的常规图像参照：12 维 RGB 直方图与最近类别中心，使用相同原图、裁切和井段分组；这不是人工专家成绩。与源标签一致的照片数，常规参照开发组 24/42、留出组 14/24；CNN 分别为 37/42、8/24。页面同时显示正负差异，不以开发组代替留出结果。可用 `python tools/m1/prepare-color-baseline.py` 复现参照方法。

图像字节、源标签、井深和外层分组保持不变。缺失的现场采样、迟到和成像记录明确标为未提供；没有新增矿物或颗粒含量标注。论文图与本例数据分别注明来源，外部图不进入识别实验。详见 [论文图例相关性核查](docs/论文图例相关性核查.md) 与案例包说明。

## 运输与加工

新增两个图解主题、10个案例和30个原生教学页签，继续采用录井的“问题—传统处理—智能方法—作用证据—结果”结构。入口：[运输](https://favorites-zhaoy.github.io/hw5/#/stage/transport)、[加工](https://favorites-zhaoy.github.io/hw5/#/stage/refining)。

严格保留TXT的CV／TS／OPT／NLP分类，运行双端负压波、CNN、GRU、约束压气调度、Kalman漂移校正、字符文本审核和技能容量分派。真实透明容器照片、实验轴承数据、公开FCC仿真、脱丁烷塔模拟及受控情景分别标明，不改写数据对象或单位。三个页签共享当前资料和参数，可导出原始输入、参照、来源及模型哈希；弱于简单参照的结果保留。

两张主题图通过内置imagegen参考已有浅色微缩图生成，只解释业务，不参与训练。运行`npm run downstream:build`整理已保存资源；数据选择、授权、算法和复现步骤见[运输加工案例说明](docs/运输加工案例说明.md)。

## 在线部署

GitHub Pages从`main`分支根目录发布，`.nojekyll`让HTML、JavaScript和案例资源按静态文件提供。推送到`main`后自动部署；使用哈希路由，M1等场景链接可以直接分享。

在线网站的案例导入仍保存在当前浏览器，不能作为全班共享上传服务。源码和提交包保留在仓库中，可继续下载离线运行。

## 检查

安装 Node.js 后运行：

```sh
npm test
```

测试使用内存存储与 DOM 模拟，覆盖旧包导入、演示挂载、旧存档恢复、场景字段保留、路由行为、五阶段归组、阶段切换、搜索与案例筛选、动效开关与资源清理；不能替代真实浏览器的视觉检查。课程图解采用原生 SVG 与 CSS 动画，系统偏好减少动态效果时默认暂停。

封面图片由项目使用者提供，原始像素保留在 `assets/images/oilfield-cover.png`，页面通过 CSS 校正方向。
