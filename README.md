# 石油勘探开发的智能化可能性地图

可视化导论课程项目初版。以 13 个石油作业环节、61 个候选场景为目录，把专业背景、案例流程和浏览器内交互演示连接起来。

## 运行

下载或克隆仓库后，使用 Chrome 或 Edge 打开根目录的 `index.html`。无需安装依赖或启动后端。

如需 HTTP 预览，可在此目录运行 `python -m http.server 8080 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8080`。

## 首页

- 用户提供的油田摄影封面，搭配明亮朱红色主题。
- 动态河流场景地图：红色流光沿弯曲主河道穿梭，阶段节点与两岸场景通过支流相连；支持搜索、案例筛选、悬停高亮和动效暂停。
- 五类方法探索器，支持点击和方向键切换。
- 环节 × 方法矩阵，可切换候选场景分布与案例覆盖。
- “读懂专业背景 → 拆解案例流程 → 运行交互演示”学习入口。

## 案例接入

录井环节（`#/stage/mudlogging`）用前端几何体重建为 2.5D 等轴测现场：井架与地层剖面、分离循环系统、四个分析工作站、深度对齐屏和报告工作台。安全帽工人由头部、躯干、肩肘关节和腿部组成；悬停或键盘聚焦时，会操作显微镜、指示曲线、检查荧光样品或编写报告，其他板块虚化。网页文字独立排版，人物、设备、岩石与图表都由代码生成，场景不使用图片截图或位图纹理。

三维运行库保存在 `assets/vendor/three-r160.min.js`，采用 MIT 许可证，见同目录 `THREE-LICENSE.txt`。仍可直接以 `file://` 打开，无 CDN 或后端依赖；不支持 WebGL 时用 Canvas 投影同一组三维几何体。模型按可见区域加载，工人只在聚焦时播放动作；切页释放几何体、材质、上下文与监听器。支持暂停动效、系统减少动态效果偏好、方法选择和点击进入原有场景讲解。五个完整案例仍需分别接入。

保留原门户的案例包协议。点击“添加案例”，选择解压后的案例文件夹，或多选包内文件。上传器支持整页 HTML、JS 模块和复用内置演示三种形式。

`firstbreak-pick-case/` 是原格式初至波案例包，可以直接导入。`assets/cases/` 中包含原模板及默认测井案例。详细字段见 [接入指南](docs/如何添加新案例.md)。

上传记录保存在当前浏览器的 `localStorage`，不会写回源码目录。换浏览器或电脑时需要重新导入；提交作业时请保留完整案例包。

## 检查

安装 Node.js 后运行：

```sh
node --test tests/regression.cjs tests/mudlogging3d.cjs
```

测试覆盖旧包导入、演示挂载、旧存档恢复、路由、首页河流、悬停聚焦、工人关节动作、三维几何投影、WebGL 资源释放与软件渲染回退。测试使用内存存储、DOM 与渲染器模拟，不能替代真实浏览器的视觉检查。系统偏好减少动态效果时，动效默认暂停。

封面图片由项目使用者提供，原始像素保留在 `assets/images/oilfield-cover.png`，页面通过 CSS 校正方向。
