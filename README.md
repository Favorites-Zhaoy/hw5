# 石油勘探开发的智能化可能性地图

可视化导论课程项目初版。以 13 个石油作业环节、61 个候选场景为目录，把专业背景、案例流程和浏览器内交互演示连接起来。

## 运行

在线访问：[课程网站](https://favorites-zhaoy.github.io/hw5/)；[M1案例流程](https://favorites-zhaoy.github.io/hw5/#/scene/m1?case=m1-cuttings&tab=flow)。

下载或克隆仓库后，使用 Chrome 或 Edge 打开根目录的 `index.html`。无需安装依赖或启动后端。

如需 HTTP 预览，可在此目录运行 `python -m http.server 8080 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8080`。

## 首页

- 用户提供的油田摄影封面，搭配明亮朱红色主题。
- 动态河流场景地图：红色流光沿弯曲主河道穿梭，阶段节点与两岸场景通过支流相连；支持搜索、案例筛选、悬停高亮和动效暂停。
- 五类方法探索器，支持点击和方向键切换。
- 环节 × 方法矩阵，可切换候选场景分布与案例覆盖。
- 首页直接提供岩屑案例入口，按“认识现场 → 整理数据 → 辅助识别”建立学习路径；也可继续从场景地图探索其他环节。

## 案例接入

录井环节（`#/stage/mudlogging`）使用用户提供的现场图解，叠加原生 SVG 流动箭头、信号曲线、图像扫描和荧光动画。选择 CV 放大 m1/m3，TS 放大 m2/m4，NLP 放大 m5；点击图画进入原有场景讲解，已导入的案例仍由注册表自动展示。支持动效暂停、键盘操作和小屏放大图卡。图解是导航与教学示意，五个完整案例仍需各自接入。网页使用 241 KB 的桌面 WebP 与 100 KB 的手机 WebP，保留原始 PNG；提前加载当前尺寸的底图，加载时显示内嵌缩略图，底图就绪后显示动画。

保留原门户的案例包协议。点击“添加案例”，选择解压后的案例文件夹，或多选包内文件。上传器支持整页 HTML、JS 模块和复用内置演示三种形式。

`firstbreak-pick-case/` 是原格式初至波案例包，可以直接导入。`assets/cases/` 中包含原模板及默认测井案例。详细字段见 [接入指南](docs/如何添加新案例.md)。

m1 岩屑岩性辅助识别案例已接入 `#/scene/m1`，三页为“专业背景、案例流程、辅助识别”。专业背景按真实背景、技术前沿、示例数据、技术难度与参考方向组织，图解、论文原图与说明相互补充。案例流程只讲数据整理：保留原图、对应井深、检查图像与重复、统一画面、整理标签、按井段分组、交付清单；每步都有当前样品的图或数据。第三页把真实照片、原始岩性、识别结果和分类得分按井深对应，点选后显示原图、三类得分与类别响应。

当前提交文件夹为 `m1-cuttings-case/`，压缩包为 `submissions/m1-cuttings-case-v2.0.1.zip`，解压后按原协议导入；直接打开 `demo/index.html` 也能离线运行。入口已内嵌样式、脚本、66 张原始 JPEG、研究图例和固定实验结果。样品选择会在三页之间延续，切换页面时回到章节开头；支持导出数据清单和当前组识别记录。

识别采用 ImageNet 预训练的 ResNet-18，冻结卷积层，只拟合三类线性分类层。中心 72% 裁切后缩放为 224×224。开发用 42 张照片按 12 个井段组逐组留出，另有 24 张照片分为 5 个留出组；每折的缩放参数和分类层只用该折开发资料拟合。页面展示已经计算并保存的结果及逐类别 Grad-CAM，不在浏览器里重新训练或运行网络。实际开发组一致率 88.1%，留出组 33.3%；保留全部差异，不用论文性能替代本例结果。这是曾在旧版展示过的单井公开教学子集，不能声称独立盲测或新井效果。

图像字节、源标签、井深和外层分组保持不变。缺失的现场采样、迟到和成像记录明确标为未提供；没有新增矿物或颗粒含量标注。论文图与本例数据分别注明来源，外部图不进入识别实验。详见 [论文图例相关性核查](docs/论文图例相关性核查.md) 与案例包说明。

M1 网站入口统一为 `#/scene/m1?case=m1-cuttings&tab=bg`。旧版 M1 案例链接会对应到当前页，浏览器保存的旧版课程包不再自动挂载；其他自定义案例继续按原协议使用。已移除重复的开场大图，独立 HTML 直接进入三部分内容。

可编辑源文件在 `tools/m1/`。修改后运行 `node tools/build-m1-case.cjs` 重建页面、清单与门户注册文件。复现实验需 Node.js、Python、NumPy、Pillow、scikit-learn、PyTorch 和 torchvision，运行 `python tools/m1/prepare-resnet.py`；首次从官方地址取得 ResNet-18 权重。实验制作工具不是网页运行依赖。

上传记录保存在当前浏览器的 `localStorage`，不会写回源码目录。换浏览器或电脑时需要重新导入；提交作业时请保留完整案例包。

## 在线部署

GitHub Pages从`main`分支根目录发布，`.nojekyll`让HTML、JavaScript和案例资源按静态文件提供。推送到`main`后自动部署；使用哈希路由，M1等场景链接可以直接分享。

在线网站的案例导入仍保存在当前浏览器，不能作为全班共享上传服务。源码和提交包保留在仓库中，可继续下载离线运行。

## 检查

安装 Node.js 后运行：

```sh
node --test tests/regression.cjs tests/m1-preview.cjs tests/routes-assets.cjs
```

测试使用内存存储与 DOM 模拟，覆盖旧包导入、演示挂载、旧存档恢复、场景字段保留、路由行为、河流几何、筛选重排、动效开关与资源清理；不能替代真实浏览器的视觉检查。河流采用原生 SVG 与 CSS 动画，系统偏好减少动态效果时默认暂停。

封面图片由项目使用者提供，原始像素保留在 `assets/images/oilfield-cover.png`，页面通过 CSS 校正方向。
