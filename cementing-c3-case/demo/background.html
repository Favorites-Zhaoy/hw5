01CONTEXT

真实背景

裂缝、孔洞或诱导破裂可接纳浆体，导致返出减少。泵入与返出之间的缺口是线索，但井筒储集、滞后和传感器误差也能产生暂时不平衡。

井底压力需要与地层条件相容。过高可能增加诱导漏失风险，过低可能削弱压稳能力；本课的压力裕量只是生成器输入，不能替代实际地层压力评价。

05GLOSSARY

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
漏失 / Lost circulation循环液流入地层使返出不足。本课合成二分类事件。
返出缺口 / Flow deficit泵入与返出量之间的差。固定门槛参照，L/s。
池体积 / Pit volume地面循环液池的体积。变化量是输入线索。
压力裕量 / Pressure margin距离教学上界尚有多少余量。生成器提供，不能当现场评价。
逻辑回归 / Logistic regression把多个输入组合成0–1分类得分。6个特征，权重真实拟合。
不均衡 / Class imbalance正常记录比异常记录多。保留原占比，不能只看准确率。
误报 / False positive正常记录被标为待复核。消耗复核资源。
漏报 / False negative模拟漏失记录未被标记。门槛代价中的FN项。
精确率 / Precision标记的记录中有多少是真实模拟异常。TP/(TP+FP)。
召回率 / Recall模拟异常中有多少被标记。TP/(TP+FN)。
校准组 / Calibration group拟合之后专门选门槛的独立作业。与拟合组、保留组互不重叠。
约束搜索 / Constrained search先检查容量，再比较FN与FP代价。38个门槛的实际枚举。
拟合组 / Fit groups用来学习权重、标准化尺度的模拟井或作业。整组隔开，不能把同一井相邻点随机分到两边。
保留组 / Held-out groups训练之前就隔开的另一组资料。只检查泛化，不能用其标签挑模型。
合成资料 / Synthetic data由公开脚本和固定种子生成的教学资料。有可复算的标签，但不证明现场有效。
