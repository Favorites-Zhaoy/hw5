05GLOSSARY

术语对照表

专业术语大白话最接近的计算机概念 / 本课用法
实体 / Entity图中可独立指认的对象。工具族与证书都是实体。
关系 / Relation连接实体与属性的有向语义。例如certifiedBy、fitsCasing。
三元组 / Triple主体、关系、客体的结构。本课额外保留来源编号。
本体 / Ontology实体类型与关系类型的约定。约束哪些对象能够相连。
证据路径 / Evidence path从查询对象到支持属性的关系链。工具→证书→具体条件。
硬约束 / Hard constraint必须成立的条件。不能用便宜或高分抵消。
检索 / Retrieval根据条件查出结构化证据。确定性遍历本地图。
经典AI / Symbolic AI用显式知识和规则进行推理。本课实现，不称为深度学习。
合成教学资料 / Synthetic data由明确生成器产生的虚构资料。数值用于复算，不代表油田成绩。
保留组 / Held-out group拟合前隔开的另一批条件或模拟井。不参与权重拟合。
约束 / Constraint候选必须满足的明确边界。先判断可行，再比较目标。
模型残差 / Residual模型输出与观测或参考值的差。保留误差，避免只展示最佳曲线。
